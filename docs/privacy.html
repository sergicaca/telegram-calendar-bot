Política de privacidad

Última actualización: 2026.

Qué es este bot

Es una herramienta de uso estrictamente personal, creada y operada por una única persona para su propio uso. No se ofrece como servicio a terceros ni se distribuye públicamente.

Qué datos trata

El bot accede, únicamente para su propietario, a: eventos de su Google Calendar, su lista de Google Tasks, y los mensajes que él mismo envía por Telegram. No se recopilan datos de ninguna otra persona.

Cómo se usan

Los datos se usan solo para mostrar recordatorios, crear/consultar eventos y gestionar tareas pendientes del propio propietario. No se venden, comparten ni ceden a terceros, salvo las llamadas técnicas necesarias a las APIs de Google (Calendar, Tasks), Telegram y Anthropic (para interpretar los mensajes) estrictamente para prestar la funcionalidad descrita.

Almacenamiento

Los eventos y tareas se almacenan en la propia cuenta de Google del usuario (Calendar/Tasks). El bot no mantiene una base de datos propia de contenido personal.

Contacto

Para cualquier duda sobre esta política, contactar con el propietario de este proyecto.
